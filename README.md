This repository is for our Art Resources Group Project. Our group will work together to research, collect, and organize useful art resources.

- Collaborate as a team using GitHub.
- Make individual contributions to the shared repository.
- Practice using Git commits and collaborative development.

## Collaboration
Each group member will contribute to the project through GitHub. Individual changes and contributions will be tracked through Git commits.
